# Mission Logs Directory

This directory contains mission telemetry data and documentation generated by the Flight Data Recorder (FDR) system.

## Directory Structure

```
logs/
├── space_state_YYYYMMDD_HHMMSS.log    # Runtime debug/info logs
└── missions/                           # Mission data archives
    └── {mission_name}_{timestamp}/     # Per-mission folder
        ├── telemetry.csv               # Complete telemetry time series
        ├── events.json                 # Mission events log
        ├── summary.json                # Mission summary (machine-readable)
        └── mission_report.txt          # Human-readable mission report
```

## Telemetry Data (telemetry.csv)

Each row represents a telemetry frame with the following columns:

### Time
- `t` - Simulation time (days from epoch)
- `met_sec` - Mission Elapsed Time (seconds)
- `met_str` - MET formatted (HHH:MM:SS.mmm)

### Position (SSB Frame)
- `r_x`, `r_y`, `r_z` - Position components (AU)
- `r_mag_au` - Position magnitude (AU)
- `r_mag_km` - Position magnitude (km)

### Velocity (SSB Frame)
- `v_x`, `v_y`, `v_z` - Velocity components (AU/day)
- `v_mag_aud` - Velocity magnitude (AU/day)
- `v_mag_kms` - Velocity magnitude (km/s)

### Mass
- `mass` - Total mass (kg)
- `dry_mass` - Dry mass (kg)
- `propellant_mass` - Main propellant (kg)
- `rcs_propellant_mass` - RCS propellant (kg)

### Attitude
- `q0`, `q1`, `q2`, `q3` - Quaternion (scalar-first)
- `q_norm` - Quaternion norm (should be ~1.0)
- `roll_deg`, `pitch_deg`, `yaw_deg` - Euler angles (degrees)

### Angular Velocity
- `omega_x`, `omega_y`, `omega_z` - Angular rates (deg/s)
- `omega_mag` - Angular rate magnitude (deg/s)

### Propulsion
- `thrust_n` - Current thrust (N)
- `throttle` - Throttle setting (0-1)
- `isp_s` - Specific impulse (s)
- `mdot_kgs` - Mass flow rate (kg/s)
- `thrust_dir_x/y/z` - Thrust direction (unit vector)
- `accel_thrust` - Thrust acceleration (m/s^2)

### Body-Relative Data
- `primary_body` - Current primary body name
- `altitude_km` - Altitude above body surface (km)
- `distance_km` - Distance to body center (km)
- `speed_rel_kms` - Speed relative to body (km/s)

### Orbital Elements (when in orbit)
- `sma_km` - Semi-major axis (km)
- `eccentricity` - Orbital eccentricity
- `inclination_deg` - Inclination (degrees)
- `raan_deg` - Right ascension of ascending node (degrees)
- `arg_periapsis_deg` - Argument of periapsis (degrees)
- `true_anomaly_deg` - True anomaly (degrees)
- `orbital_period_hr` - Orbital period (hours)

### Distances to Bodies
- `dist_sun_km` - Distance to Sun (km)
- `dist_earth_km` - Distance to Earth (km)
- `dist_moon_km` - Distance to Moon (km)
- `dist_mars_km` - Distance to Mars (km)
- `dist_jupiter_km` - Distance to Jupiter (km)

### Environment
- `eclipse` - Eclipse status (bool)
- `solar_flux_w_m2` - Solar flux (W/m^2)
- `temperature_k` - Temperature estimate (K)

### Attitude Control
- `wheel_momentum_1/2/3/4` - Reaction wheel momentum (N*m*s)
- `wheel_total_momentum` - Total wheel momentum magnitude

### Communication
- `comm_earth_possible` - Earth comm possible (bool)
- `comm_delay_sec` - Light-time delay to Earth (s)

### Status
- `is_burning` - Burn in progress (bool)
- `is_coasting` - Coasting (bool)
- `event_name` - Current event name

## Events Log (events.json)

Array of mission events, each with:
- `t` - Time (days)
- `met_sec` - MET (seconds)
- `event_type` - Event type (burn_start, burn_end, staging, soi_entry, etc.)
- `description` - Event description
- `delta_v_mps` - Delta-V (if applicable)
- `mass_before_kg`, `mass_after_kg` - Mass change
- `body_name` - Associated body
- `altitude_km` - Altitude at event
- `data` - Additional event-specific data

## Usage

### Loading Telemetry Data

```python
import pandas as pd

# Load telemetry
df = pd.read_csv('telemetry.csv')

# Plot altitude over time
import matplotlib.pyplot as plt
plt.plot(df['t'], df['altitude_km'])
plt.xlabel('Time (days)')
plt.ylabel('Altitude (km)')
plt.show()
```

### Loading Events

```python
import json

with open('events.json') as f:
    events = json.load(f)

for event in events:
    print(f"{event['event_type']}: {event['description']}")
```

### Mission Report

The `mission_report.txt` file contains a human-readable summary including:
- Mission overview
- Mass budget (initial/final mass, propellant used)
- Delta-V budget (total and per-burn breakdown)
- Trajectory statistics (max/min altitudes, velocities)
- Event chronology
